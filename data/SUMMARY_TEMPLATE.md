# 中文摘要模板

> 状态：**已定稿**（2026-11-27），和 v0.4 判定器放在同一提交中冻结；冻结标签 `v0.4-judge` 指向的提交，就是本模板的冻结版本。冻结后，节礼日案例的摘要一律按本模板撰写。模板如需修改，必须另立版本，并说明修改原因；不得为了让某个案例判得更好而临时调整写法。

摘要是判定器的唯一输入，判定器不读原页。所以摘要要做到两点：

- 原页写了的条件，一个不漏、一个不改；
- 原页没写或写得含糊的，如实写明，不替原页补全，也不推断。

撰写摘要时只依据本模板和原页（或其存档），不参照判定器的代码，也不看任何策略的输出。

## 一条资料的结构

每份资料（`sources.json` 里的一项）记录：

- `title`、`publisher`、`source_type`、`url`、`archive_url`、`checked_date`、`timezone`
- `passages`：每段一个 `locator`（原页上的位置，如「Offer 日期栏、正文及 Terms and Conditions」「第 2 页 / 品牌名」）和一段 `summary_zh`

一份资料涉及多个品牌时（如活动传单），每个品牌单独写一段，`locator` 里写明品牌名。

## `summary_zh` 的写法

### 1. 有效期写在最前面

| 原页情况 | 写法 |
| --- | --- |
| 有起止日期 | `YYYY-MM-DD 至 YYYY-MM-DD：` 开头，例如 `2026-12-26 至 2026-12-31：` |
| 只有某一天 | `仅限 YYYY-MM-DD 一天，` |
| 只有开始日 | `自 YYYY-MM-DD 起限时，未写结束日。` |
| 没有日期 | 句末写 `未写有效期。` |
| 日期明显印错（如结束日早于开始日） | `有效期印为「原样」，结束日早于开始日。`，不改正 |
| 日月顺序不确定（如 `5/11 – 1/12`） | `有效期印为「原样」，日月顺序无法确定。`，不换算 |

日期一律换算成 `YYYY-MM-DD`。只有在顺序确定的前提下才换算，例如同一份资料的其他日期里出现了大于 12 的日，足以确定日月顺序；换算时在括号里注明原样，例如 `2026-11-05 至 2026-12-01（原页印为 5/11–1/12，按本传单的日/月顺序换算）：`。顺序不确定时一律不换算。

### 2. 每条优惠一句，用「；」分隔

同一份资料列了几条优惠时，每条写成一句，句与句之间用「；」。一条优惠的数值、范围、计价单位和门槛**写在同一个分句里**，不要用逗号拆开。会员资格可以写在同一句的另一个分句里。

### 3. 优惠形式

| 形式 | 写法 | 例子 |
| --- | --- | --- |
| 百分比 | `N% off` 或 `减 N%`；另有「再减」「额外」时照写 | `全店 30% off`；`特价品再减 20%` |
| 最高折扣 | 写「最高」 | `指定款最高 50% off` |
| 买一送一 | 统一写「买一送一」，送什么另外说明 | `全店买一送一`；`买一送一，送一杯价格相同或更低的饮品` |
| 单件价格 | `每件 / 每支 / 每杯 $X` | `精选身体护理每件 $12` |
| 整组价格 | `任选 N 件（杯、支）… 共 $X` | `任选 3 杯大杯果茶或奶茶共 $20` |
| 附加费用 | `另付 $X` | `加配料另付 $0.95` |

整组价格必须写出「共」或「任选」，单件价格必须写出「每件」等计价单位，不能只写 `$X`。

### 4. 商品范围

| 原页情况 | 写法 |
| --- | --- |
| 全店、全场、所有款式 | `全店` |
| 指定款、精选商品、select styles | `指定款` 或 `精选`，照原页 |
| 某一类商品 | 写原页的类别名，如 `首饰`、`身体护理`、`装备`、`床品`。类别名不必是常见词，照原页写即可 |
| Outlet 商品 | `Outlet 商品`（指商品范围，不是门店类型） |
| 任一商品均可 | `任一`，如 `购买任一饮品` |
| 有除外 | `除 … 外`，照原页列出 |

### 5. 资格与门槛

| 条件 | 写法 |
| --- | --- |
| 会员或 App 用户 | `仅限 … 会员` 或 `仅限 … App 会员` |
| 金额门槛 | `$N 以下` / `$N 以上` / `满 $N`，写出具体金额 |
| 件数要求 | `买 N 件` / `买 N 件或以上`，写出具体件数 |
| 限兑一次、售完即止等 | 照原页写 |
| 门店类型限制 | 照原页写，如 `条款写明仅限 … Outlet 门店`、`条款限定 … Outlet`。门店类型和商品范围（`Outlet 商品`）分开写 |

### 6. 门店

写明资料对应的门店，例如 `门店为 DFO Homebush 的 品牌名。` 商场门店页只记录门店身份和页面上展示的内容，例如 `门店页列出 品牌名 位于 DFO Homebush，当前展示 …。`

### 7. 缺失与含糊

- 原页没写的条件，不补。如果这个条件和判定有关（如没写有效期、没写是否限会员），写明 `未写 …`。
- 原页写法含糊的，写 `原页写法为「…」，含义不明。`，不替它选一种解释。
- 原页与同一来源的其他位置矛盾的，分别如实记录，不调和。

## 版权与引用

摘要用自己的话改写，不整段照抄。`quote` 字段只在必须保留原文措辞时使用，并且不超过 15 个词。

## 撰写与核对流程

1. 依据原页或其存档撰写摘要，严格按本模板。
2. 标注人逐段对照原页核对。有出入的，以原页为准修改摘要，并记录在核对清单里。
3. 核对完成后生成 `SHA256SUMS`，冻结资料。
4. 之后才开始标注。
